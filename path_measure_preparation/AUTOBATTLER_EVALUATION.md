# 自走棋 Agent 评估指标与比较协议 V0.1

日期：2026-11-21。目标：用可公开复核的同类研究常用指标评价本项目，同时把同环境对比与跨游戏文献参考分开。

## 同类工作的核心指标

Ma 和 Wang 的预印本《Build, Don't Play: Self-Improving LLM Research Agents Develop a Hearthstone Battlegrounds AI That Rivals Top Players》，2026，arXiv:2610.33845，表 3 使用平均名次、第一名率、前四率；作者称在同一模拟器版本、固定对手评测及 3 个未见种子下，每个表格行评估 24,576 局。论文还单独报告更难对手、真人天梯与决策耗时。它是酒馆战棋，不是本项目 TFT 模拟器；数值仅为文献参考，不能直接与我们对比。论文：https://arxiv.org/html/2610.33845

TFT 环境和训练项目 tft_rl 的公开结果也报告平均名次、前四率和末位率，并在同一环境比较随机合法策略、行为克隆、PPO 和规则策略。项目说明：https://github.com/calebyhan/tft_rl 。项目自己的结果、规则版本和对手与本研究不同，不作为本模型成绩。

## 本项目的主要结果

固定八人对局并报告有效对局数 N：

1. **平均最终名次**：`mean(rank)`，越小越好；八人完整排名每个位置恰一次且等权时，同水平对称座位的总体均值是 4.5。4.5 不保证任何特定座位或对手池的随机策略都达到此值。
2. **前四率**：`count(rank <= 4) / N`，越大越好。
3. **第一名率**：`count(rank == 1) / N`，越大越好。

必须先冻结并检查并列名次处理。例如本次试运行对同一 parallel step 淘汰取名次中位值；当并列跨越第一或前四边界，这种规则的阈值计数不等同上游真实结算或分摊胜率，单独记录 `tie_group`, `occupied_ranks` 并报告其数量，先验证模拟器的真实结算机制；在规则验证前不把试运行的名次作为最终基准。不同方案不得混用。若使用 fractional credit 等替代 tie 计分，也需命名并同时报告定义。

## 辅助指标

- 对局有效率、自然结束数、引擎上限结算数、外部超时/错误数、未能归属名次数；不要丢弃失败而只报成功局。统计口径和分母必须清楚；未确定名次不伪造名次。
- 每个决策非法动作率，统计发送给环境前后拒绝的动作；记录截断与自动 pass，不用训练损失替代游戏结果。
- 决策耗时，至少报告硬件、测量范围及 p50/p95；需要区分模型前向、完整决策和候选模拟预算。吞吐量、训练总环境步数、GPU 时间等记录以辅助解释成本。
- 按对手池、座位、训练种子和对局随机种子分层；必要时报告末位率、名次分布。
- 实验机制诊断（Gibbs ESS、最大权重、条件残差、策略更新与固定点残差）独立呈现，不冒充同类 Agent 的对局主指标。既有 15.4% 模仿动作准确率只表示相对于随机化教师标签的预测匹配，不是胜率。

## 公平对照

- 固定模拟器提交、规则、八人制、动作/信息边界、名次结算和对手池。优先比较相同代码基础：随机合法、修复后的规则基线、普通训练 Agent、扩散 Agent、扩散+Gibbs/向量场变体。动作空间不同的策略明确记录。
- 相同数据和架构时固定训练交互、更新、硬件和总预算；规划方法另报候选数、环境调用次数、时延及计算成本。不能假设扩散和非扩散架构天然同算力。
- 分离训练、验证、最终测试 seed；模型/超参只在验证集选择。至少 3 个独立训练种子作为初步要求，再分别多局评估，不把同一权重的多局当成独立训练重复。结果逐训练种子给出，并给出合适的不确定性；同时考虑共享种子及同一模型生成多局的层级结构。
- A/B 采用相同预先登记的对局 seed、座位和对手策略，重复测相同模型同 seed 来审计重现性；但不同动作可改变随机数消耗或环境轨迹，仅 seed 相同不保证相同随机事件。不要宣称使用严格相同随机未来。
- 优先记录每对局可复核的独立结果，保存 checkpoint、配置、源码提交、各随机源及对局记录。统计置信区间方式和样本量目标须预先确定；先做小规模 profiling 和统计效能规划，再决定正式对局数，不以 3 局试验结论声称提升。
- 对局面复制和候选行动模拟，绝不能复制真实未来随机数作为策略输入。AutoTavern 论文报告复制状态携带随机数会导致“看到未来”的虚假搜索收益；应按已知信息构造、对每个模拟样本重新抽取未知随机变量，并验证无信息泄漏。

## 当前数据状态

2026-11-21 一次仅 4 个训练局和 3 个评估局的试运行只用于连通性：普通模仿策略与一次 REINFORCE 更新后模型的平均名次分别约 3.50 和 3.33；对手为弱脚本、并列规则未最终审计，不能用于任何性能改善或跨论文结论。尚无本项目多 seed 正式结果，也尚未进行扩散/Gibbs/Bridge 训练。

后续代码核查表明，固定的 TFT 上游提交对同一轮多名玩家淘汰会按内部遍历顺序依次分配不同名次；先前使用的中位名次不是上游原生规则。新多种子探索从终局 raw reward 中减去累积的 `player.reward`，按上游 `40-5*(rank-1)` 还原并检查 1–8 的唯一性；如果无法满足检查或存在多名正血量终局则标记为无效，不用虚构排名。该内部顺序可能引入座位偏差，仍须通过轮换座位、重排验证；旧中位排名实验不得直接与新结果合并。
